# 冬：越后汤泽（滑雪 + 温泉）

页面 `viz/winter/yuzawa-yukiguni.html`（繁体 `-tw.html`），视频 `output/winter/`，环境音 `viz/tools/ambient-winter.py`。已定稿。

## 结构（20 秒循环）

一张雪国全景，镜头平移和推拉，段落之间直切：

| 时间 | 画面 | 大字 |
|---|---|---|
| 0–3.3 | 新干线出隧道，镜头跟着慢慢右移 | 穿过隧道 就是雪国（——川端康成《雪国》） |
| 3.3–8.7 | 跟拍滑雪（透视的雪坡）：刻滑 → 直滑 → 冲线后横过雪道刻刹减速、举单手 | 出站就是雪场 / 雪又厚又软 |
| 8.7–13 | 露天温泉：热气、漂着的雪见酒托盘、两人碰杯 | 滑完雪泡温泉 |
| 13–20 | 拉远到全景，一路推回隧道口；最后地面震动、洞口变亮，第 0 秒列车冲出 | 一小时到雪国 |

## 这一集的特别处理

- 标题横笔上积雪，并关掉字面反射（`reflect: false`）。
- 全片字色固定：大字暖白、关键词琥珀色，小字都用暖色（2026-10-23 起；之前的「由冷变暖」「雪地上换深蓝字」不用了）。
- 滑雪段背景是白雪：大字加一圈浓的深色光晕；画面上方的渐暗加深，托住标题和旁白。
- 碰杯：两人用离对方远的那只手，手臂被身体挡住，只露出拳头和大杯啤酒。

## 试过没用的

- 2.5D 一镜到底的立体世界：太复杂，焦点乱。
- 飞雪遮挡的转场：刻意感强，改成直切。
- 急停、原地举手：不像真的比赛收尾。
- 中下方大字和长冈一致用极简写法：细字重、宽字距、淡字影，底下不压暗。
