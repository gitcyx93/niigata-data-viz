## 使用

下载 HTML 后直接打开，点「有声播放」。环境声音轨、播放器与字体都在单文件里，不需要服务器或网络。默认静音，避免浏览器禁止自动有声播放，也不在打开文件时突然发声。

- 点有声播放会从当前画面位置开始；点静音不停止画面。
- 暂停、拖动、章节跳转、重播和「看后半段」同步声音。
- 拖动和章节跳转沿用原来的暂停行为，按播放从选中位置继续。
- 切到后台时暂停声音与时间，返回后从原位置继续。
- 浏览器/系统中断 AudioContext 时，已启动的有声画面使用冻结的音频时钟，不让画面悄悄超前。
- 解码或声音权限失败时退回无声播放并显示可重试提示。

## 声音设计

本轮没有音乐、旁白、钟声、拍手、海浪或额外鸟鸣，也没有合成白噪声底。

全部由四份 CC0 实录裁切、滤波和混合而成。它们不是在弥彦录制的声音；索道素材还是法国滑雪场的**站内**录音，只抽取低频机械底，不宣称还原弥彦车厢。

| 时间 | 声音 |
|---|---|
| 0–2.2 秒 | 很轻的空气/风底，沿当前 A 的桥景推进，进入夜景时引入林间枝叶 |
| 1.65–5.6 秒 | 一阵连续增强的干叶声，随飞叶增多、加速逐渐扬起，不在中间人为静下来 |
| 5.6–8.1 秒 | 同一阵叶声跨过夜景→鸟居的直切，自然衰减，没有另加“嗖”的转场音 |
| 8–11.4 秒 | 林间底声逐渐退出；9.8 秒起引入机械底，随着车厢露出变得可辨 |
| 11.4–15 秒 | 缆车机械低鸣，到看海时逐渐淡出，不突然切断 |
| 14.6–25.2 秒 | 开阔处风声；没有近距离海浪。末尾约一秒收住，自然重新播放 |

飞叶使用较近、细碎的质感与轻微左→右声像。原始干叶录音包含用鞋拨动叶堆，制作时高通去除低频脚步冲击，轻压瞬态；没有拿它当作新的脚步事件。长风声使用连续原始片段，不用短循环重复。

### 音量

以保留间歇与远近差别为先，不做广告式响度拉满。当前 MP3 检测为约 **-23.27 LUFS**，true peak **-8.27 dBTP**；音量未顶到满幅。各分轨使用同一主增益，保留单声道兼容性。

## 复现

```sh
# 需要 Python numpy/scipy 和 ffmpeg/ffprobe；不联网下载素材。
python3 viz/tools/ambient-yahiko.py

# Node 22+ 与本机 Chrome/Chromium；硬件输出静音，避免测试突然发声。
node viz/tools/check-yahiko-ambient.cjs
# 非默认 Chrome 路径：BROWSER_EXE=/path/to/chrome node ...
```

构建脚本校验原始音频 SHA-256，保留四份可再混音分轨，重新生成 MP3 并内嵌到 HTML。每次构建都从当前 `yahiko-v11-refined.html` 复制渲染代码与开场选择器，不维护一份容易落后的画面副本；混音记录包含画面源文件哈希。可复用的音频控制代码在 `viz/common/ambience-player.js`，页面接入在 `viz/common/yahiko-audio-transport.js`，构建时内嵌，不改变原来的 `series.js`。

## 验证与限制

已完成 Chrome 自动检查：

- 与最新无声精修版 A 的 13 个时间点、C 开场的 3 个时间点逐像素比较一致，画面和 25.2 秒镜头时间未变。
- 播放时切换 A/C 会同时重置画面与声音到第 0 秒；暂停时切换仍保持暂停。
- 默认无 AudioContext、无自动声音、无外部 HTTP 请求。
- 真实输入点击开启声音，解码为精确 25.2 秒；播放、暂停、拖动、跳章节、重播与静音/解除静音都通过。
- 解码中暂停、快速取消开启、连续重播不会留下叠加的旧声音；解码失败与不支持 Web Audio 时安全退回无声。
- 模拟 visibilitychange 验证后台暂停/恢复；直接 suspend/resume AudioContext 验证中断时冻结音频时钟。
- 完成一轮实际 Web Audio 主时钟播放，最大画面/音频时钟差记录在 `reference/yahiko-v11-ambient/validation.json`。
- 390、768、1440 CSS 像素宽度无水平溢出；减弱动态效果偏好下默认不自动播放。

**没有宣称完成主观试听或手机扬声器/Safari 实机验收。** 当前环境可做音频信号和浏览器同步检查，但没有可用的听觉审阅入口：尝试的视频音轨分析工具需要未配置的 Gemini 访问，因此未用于质量结论。未登录新账号、未上传素材到该服务。仓库交付仍是 HTML 与音频，不是 MP4。
