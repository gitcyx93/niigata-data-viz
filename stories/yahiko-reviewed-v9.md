# 弥彦 v9：独立审查后的修订

文件：`viz/autumn/yahiko-reviewed-v9.html`。基于 v8 另存，原文件不动。26 秒，1080×1920，无声，内嵌字体与绘制代码，可单独打开，默认播放，支持暂停/拖动/章节跳转。

## 本轮修改

- 移除地图开合与返回流程，以完整夜景作第 0 秒封面。集中飞叶和倒影保留。
- 时间：夜景 0–4.5 / 鸟居 4.5–7.5 / 林中拜殿及升起 7.5–12 / 缆车 12–16.5 / 日落 16.5–26。
- 林中拜殿先持续轻移约 2.2 秒，然后升起。没有恢复正面近景、冲刺模糊或手指点击。
- 升起背后的背景改用下一镜实际使用的 `ascentNew`，车厢使用相同时间、投影和索道。前景杉林下沉退出后，直接延续同一绘制，消除旧版车厢位置/尺度跳变；不再用旧山坡的小车厢假装匹配新镜头。
- 旁白缩短，每句仅保留一个信息；第 0 秒已显示整句。换句保留首个短语可读，其余字逐字出现，取消句间空白；此项是为“全程可见”采用的本页适配，不修改系列公共文件。
- 封面大字保留到夜景结束前；其他大字与对应旁白错开约一秒。神社副标题统一简体。
- 片尾两行压缩为“缆车傍晚停运 / 看夕阳记得算好时间”，20.5 秒开始，补充“出发前确认末班时间”21.2 秒开始，均保持到结尾。具体 16:40 时刻与 Skyline 信息留给发布文案，避免时刻过期或误当全年承诺。
- 更新章节按钮与自动播放，修正浮点时间落在上一镜边界的问题；修正片尾越过循环长度导致提醒错误出现在第 0 秒的问题。

## 独立文件与字体

这是另存的独立版本；共用代码区与原 v8 相同，本页旁白适配在共用代码区外，不影响其他集。沿用 v8 内嵌字体，检查了新旁白和片尾的每个字符都在已有思源黑体内嵌 unicodeRange 中（missingGlyphCoverage 为空），因此本轮未重新裁剪字体，也未运行会覆盖共用代码的 embed-font。没有增加外部字体依赖。未来增加字形时应重新构建字体并保留本地旁白适配。
