## 人物、飞叶与牌匾

- 两个人改为纯近黑剪影：头部相靠、手臂环抱，手掌藏在身体后面；不再彩色走路。栏杆在人物前重绘，保留轻微共同晃动及淡倒影。
- 每次集中风使用460片不同距离的叶子，不是460个等大的粒子。起点更靠近岸边，向上、向右扬起；近叶更大、远叶较小。第二阵风跨越5.6秒切点，两侧使用同一全局时间，因此不反向、不重新生成位置。
- 夜景镜头位移用慢起、后段加快的曲线；实测相机横向速度从约3.74px/s增加到61.46px/s。没有放射状模糊、倒放或拉回封面。
- 牌匾原有问题包括字体未加载就烘焙、宽高不适合四字竖排、只取对角点画矩形。新版在字体就绪后生成纹理，按四个投影角点逐行贴图，收窄匾宽；局部检查确认“弥彦神社”完整，无缺字框。保留简体画面约定，不宣称复刻原匾书法。

## 旧 GPT 缆车对比与取舍

实际提取并渲染了两个历史分支，不仅凭印象：

1. `gpt/review`，`d6d0ab3` 的 `yahiko-autumn-night.html`：两侧陡坡和深谷最好，车厢从左下明显上行；但树冠颗粒、远处方格平原、偏灰黄的秋色不如新版本。
2. `gpt/yahiko-refine-2026-10-24`，`03d13b6` 的 `yahiko-gpt-refined.html`：车厢和田地较细致，画面更明亮，但坡面偏黄褐，天空/平原偏多。
3. v10：红叶颜色和车体细节更好；镜头过度跟随，屏幕上的车厢位移被抵消，右前坡偏低，峡谷感变弱。

[三版同段对照](../reference/yahiko-reviewed-v11/cable-comparison.png)。

本轮选择：保留新车体与红叶颜色，恢复早期 GPT 的右侧高坡/深谷关系。车厢画面速度从 v10 约42px/s向右、14px/s向上，调整为约113px/s向右、41px/s向上；车体保持等比，不靠拉宽或缩放跳变制造速度。切点前后仍是相同投影和时间曲线。

## 字体构建与复查工具

这次增加了交通、日期文案，不能仅沿用旧版按字裁剪的字体。新增独立构建工具 `viz/tools/embed-yahiko-fonts.cjs`，从固定版本的 Fontsource 字体包嵌入所需完整 unicode 字块，避免覆盖本页旁白适配。共用 `series.js` 不改。

依赖通过 NODE_PATH 或正常 Node 模块路径提供：
- `@fontsource-variable/noto-sans-sc@5.3.1`
- `@fontsource-variable/sora@5.2.6`
- 验证另需 `playwright`

```sh
node viz/tools/embed-yahiko-fonts.cjs viz/autumn/yahiko-reviewed-v11.html
# 使用 Playwright Chromium；或通过 BROWSER_EXE 指定本地 Chrome / Edge
node viz/tools/check-yahiko-v11.cjs
```

字体依然为思源黑体同源 Noto Sans SC 与 Sora，SIL OFL。无需网络字体即可打开交付文件。
