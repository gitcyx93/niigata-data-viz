# 汤泽滑雪：Three.js 试作与自检迭代

分支：`gpt/yuzawa-ski-3d`。基线：`8184a23`。
用户要求自己先试作、按结果优化后再交付，不提交未经自检的草稿。

## 边界

仅替换 `viz/winter/yuzawa-yukiguni.html` 中3.3–8.7秒的滑雪图像。文字区源码、字体、出现时间、人物动作阶段时间、其他镜头、20秒总长与循环全部保留。没有改弥彦、高田或长冈，也没有生成译版。

原 `SKI3D.at(t)` 仍提供横向/前进轨迹和刻滑、直滑、横刹、举手时序；三维场景将人物高度与姿态贴到新的坡面，并使用新的斜前方相机。这不是声称内部三维机位和地形与旧二维投影完全相同。

## 使用的工具

- Three.js `0.180.0`：离屏WebGL2画布、地形、灯光、阴影、立体雪树与滑雪者。
- esbuild `0.25.10`：裁剪并内嵌浏览器代码，最终仍是单个离线HTML，不访问CDN。
- Chrome headless + CDP：后台渲染、抽帧、回归与运动采样。没有打开GUI制作软件或操作用户鼠标键盘。

场景源文件：`viz/winter/yuzawa-ski-3d.js`。
构建：`viz/tools/build-yuzawa-ski3d.cjs`。
检查：`viz/tools/check-yuzawa-ski3d.cjs`。
Three.js许可证：`reference/licenses/three-MIT.txt`。

构建依赖可放在项目外目录，使用 `NODE_PATH` 指向其node_modules：

```sh
npm install --prefix <dependency-dir> --ignore-scripts --no-audit --no-fund three@0.180.0 esbuild@0.25.10
NODE_PATH=<dependency-dir>/node_modules node viz/tools/build-yuzawa-ski3d.cjs
BROWSER_EXE=<chrome-path> node viz/tools/check-yuzawa-ski3d.cjs
```

无需让用户安装Node或这些依赖来观看最终HTML。观看需要WebGL2；初始化失败时保留旧Canvas滑雪镜头作为兼容回退，并在控制台说明，不把回退渲染算作三维检查通过。三维画布在影片计时开始前预热，避免切到3.3秒时才编译场景。

## 自检后的实际迭代

1. **第一版俯拍过高**：整幅画面几乎只有白地。降低机位、调整坡面与视线关系，让雪树和远处山体进入画面；不是只把天空提亮。
2. **树像规则积木**：从规则圆锥改成有小幅不对称的枝层，添加积雪团块和三维朝向；树成组放在雪坡侧后方，不围成狭窄的道路。
3. **人物部件有拼接感**：补充雪镜、衣服拉链/口袋、雪靴、固定器和独立双板；四肢连接改为圆润几何。侧身时发现胸前平条悬在外面，改成贴合衣服曲面的条带。
4. **雪板与雪痕连接**：双板跟随坡面法线，缩小离地间隙；雪痕按板的实际朝向偏移，而非只在世界x轴两侧画两条线。雪杖下端也避免明显穿入雪地。
5. **运动与接地**：保留原转弯/减速/举手时间，增加接触阴影、细雪粒与粉雪雾；镜头跟随大方向，让人物转弯产生相对位移。
6. **性能**：场景初稿约77.5万三角形，收减树数量与几何细分后约31.9万、58个绘制调用（测试采样）。保留模型轮廓与必要阴影，不按首稿的重负载交付。

不使用照片、AI生成图或外部角色素材。当前是风格化三维插画，不宣称写实滑雪模拟或实景复刻。

## 最终检查

- 新旧文字源码、字体数据、字幕时间、主循环镜头曲线、碰杯时间和原滑雪轨迹输入一致。
- 0、1.5、3.29、8.7、10.8、13、14.5、16.2、17.8、19.8、19.99秒11个非滑雪采样帧与基线逐像素一致。
- 三维场景实际启用WebGL并绘制，不是兼容回退；无捕获脚本异常、控制台error或外部HTTP请求。
- 三维同一时刻往返渲染一致；采样的板面与地形高度差小于5厘米；包围范围未越出画面或侵入下方大字区域。
- 31个滑雪时刻连续取样，审阅转弯、直滑、横刹和举手；实际RAF驱动完整20秒并进入下一轮。
- 390/768/1440三种预览宽度无水平溢出。

证据位于 `reference/yuzawa-ski3d/`：`comparison.png`、`ski-motion.png`、`keyframes.png`、完整单帧、连续抽帧与 `validation.json`。

验证采用SwiftShader软件WebGL，不能据此承诺正常浏览器或手机的实时帧率；没有手机实机或人工连续视频验收。建议用开启硬件加速的Chrome/Edge观看。
